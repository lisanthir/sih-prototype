# AYUSH SETU — SIH 2026 Prototype

Prototype for SIH26044: Portal for Academia–Industry Collaboration for Skill Mapping, Internships & Placement.

## Included
- Four role dashboards: Student, College/SPOC, Industry/Recruiter, Ministry/Admin
- AYUSH skill mapping and skill-gap analysis
- Explainable opportunity matching
- Application tracking
- Advanced verification concept
- Ministry workforce analytics
- Career assistant concept
- Responsive desktop/mobile layout
- Synthetic/sample demo data

## Run
Open `index.html` in a modern browser. No build step or server is required.

All metrics, people, opportunities and outcomes shown in the prototype are sample/synthetic data.
